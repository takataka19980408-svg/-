# レシート家計簿

レシートを撮影・読み取りして内容を確認してから保存する家計簿アプリです。店舗別・企業別・カテゴリ別のランキングやグラフで支出を可視化できます。

## 主な機能

- レシート撮影 → 端末内OCR（Tesseract.js）で店舗名・金額・日付を自動抽出 → 内容を確認・修正して保存
- 手入力での記録にも対応
- ホーム画面で今月の支出・予算に対する進捗・カテゴリ内訳を表示
- 履歴画面で月別・カテゴリ別に記録を閲覧、編集・削除
- 分析画面で月別推移グラフ、日別支出、店舗別／企業別／カテゴリ別ランキングを表示
- CSV書き出し・JSONバックアップ/復元
- オフライン対応PWA（ホーム画面に追加可能）

すべてのデータは端末内（localStorage）に保存され、外部サーバーには送信されません。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run lint      # ESLint
```
